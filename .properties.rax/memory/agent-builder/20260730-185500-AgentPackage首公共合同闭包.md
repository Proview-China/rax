# AgentPackage 首公共合同闭包

## 粗粒度事件

Builder 首切片已形成代码式/声明式输入到现有 AgentDefinition、再经现有 Assembler 与 Harness Compiler 封装 AgentPackage 的公共合同候选。

## 当前真值

- 没有第二套 AgentDefinition；
- Package ref 含 ID/revision/digest/contract/schema；
- lock 含完整上游 provenance 与四份 Harness exact artifact refs；
- frozen time 进入 lock，Package 身份确定性一一对应；
- Compiler 不接受可拼接的 release/facts/catalog/binding 参数；
- Host、Runtime、Loop、Console、TS Wire 与 production activation 继续 NO-GO。

## 验证范围

单元测试覆盖 canonical、重复、alias 防护、身份确定性和 artifact coordinate；黑盒覆盖真实 Definition→ResolvedPlan→Harness Graph→Package 以及 omit/add/splice/reorder。

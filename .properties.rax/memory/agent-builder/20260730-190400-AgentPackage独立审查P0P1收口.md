# AgentPackage 独立审查 P0/P1 收口

## 粗粒度事件

PR #26 独立审查指出 Package ID 截断与代码式 Add 输入别名两项合同缺口，现已形成修复候选。

## 修复真值

- Package ID 从完整规范化 lock SHA-256 hex 派生，不再截取 96 bit；
- 相同前 24 hex、不同后缀的两个合法 digest 必须产生不同 Package ID；
- `AddComponent`、`AddSecretRef`、`AddExtension` 在进入 Builder 时通过现有 Definition Clone 路径深拷贝；
- 反例覆盖 Component capability slice、Extension RawMessage payload 与 SecretRef 调用方后续修改；
- Host、Runtime、Loop、Console、TS Wire 与 production/SystemReady 继续 NO-GO。
